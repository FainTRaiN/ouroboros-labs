# 우로보로스 랩스 (OUROBOROS)

판교의 차고에서 시작한 AI 스타트업이 세계를 바꾸고, 달과 태양계를 거쳐 우주의 끝에 닿는 방치형 게임.

미래를 상상하기 어려운 사람에게 세계가 어떻게 바뀌는지 하나하나 보여 주려고 만들었다.
재사용 로켓, 스카이훅, 우주 엘리베이터, 달 도시, 오닐 실린더, 그리고 그 너머까지.
모든 기술에는 실제 연구와 계획의 출처를 달았다.

## 플레이

- 브라우저에서 `index.html`을 연다. 휴대폰에서도 된다.
- 휴대폰 브라우저 메뉴에서 "홈 화면에 추가"를 누르면 앱처럼 전체 화면으로 열린다.
- 진행 상황은 기기의 브라우저에 저장된다. 다른 기기로 옮기려면 「기록」 탭의 저장 코드를 쓴다.

## 파일

- `index.html` — 화면, 연출, 입력
- `game.js` — 게임 규칙 (DOM 없음, Node에서도 돌아간다)
- `audio.js` — 소리
